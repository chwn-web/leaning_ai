## 段位自测（市场分级，面试起点是 L3）

- [ ] **L0 API 接入者**：能调通 API、跑通 demo
- [ ] **L1 Prompt 操作员**：会写 prompt、会 few-shot，但说不清为什么有效
- [ ] **L2 RAG + 工具应用**：能搭 RAG、能接工具，能跑通业务场景
- [ ] **L3 Agent 系统工程师（面试起点）**：能设计状态机与失败兜底、能自建评测集、能讲清成本与延迟的取舍、能做可观测
- [ ] **L4 产品化负责人**：有真实用户、能定指标、能带人交付

自测判据：**随便挑你一个项目，连问三层（做了什么 → 为什么这么做、代价是什么 → 踩过什么坑、怎么发现的），三层不塌才算 L3。**
