# 我的素材库（写简历、练面试都从这里取材）

> 用途：`plan/03-求职冲刺.md` 的简历模板和"项目四件套"要有东西填。这里先把你**已有的真实经历**摆出来，缺的部分标 `❓待补`，想起来就补一行。
> 纪律：只写**能讲清数字、决策、代价**的；形容词一律删。

## 2. 现职业务（TCL 光伏 · TCL 审核平台）

**一句话**：做的是企业级审核平台，已经在跑 **AI 自动审核**；另有"光伏智擎"，做**自然语言 → 数据库可执行的查询 → 图表**这类取数能力。

**为什么这是你最大的底牌**：审核类业务天生带 Agent 面试最爱的四个硬问题——
1. **判定标准由谁定**：审核口径是怎么落到规则/Prompt/模型上的？谁维护、改了怎么验证？
2. **判错谁负责**：人工复核比例多少、AI 与人工不一致时怎么处理、有没有兜底通道？
3. **怎么证明变好**：抽检多少单、一致率/召回/误杀怎么算、样本量够不够？
4. **权限与审计**：谁能看、谁能改、操作留没留痕、数据出不出域？

（这四问对应 `plan/02-项目规格.md` P4 的"审核 Agent"方向，也对应 `plan/05-高频题库.md` §4.3 自检清单。）

**脱敏要求**：简历/仓库里只写"某光伏制造企业的审核平台"，不写客户名、单据内容、内部系统截图、真实字段。可以讲**形态与数字**，不讲**数据**。

## 4. 这些素材在简历里怎么用

不要写成"参与了 XX 项目"，按四件套写（场景 / 我的关键决策与权衡 / 可验证结果 / 如果重做会改什么）：

> **AI 审核链路（脱敏）**：把原来纯人工的 X 类单据审核改造成"规则 + 模型 + 人工复核"的三段流程。**关键决策**：判定标准用结构化规则兜确定性、模型只管规则覆盖不到的模糊项；误判代价不对称（漏审 ≫ 误杀），所以阈值按漏审优先调；上线前用 N 条历史单做离线回放对齐人工结论。**结果**：❓自动处理占比 / 处理时长 / 漏检率的变化。
