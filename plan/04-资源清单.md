## 2. 课程与视频（只看这几类）

- **官方 cookbook / notebook**（OpenAI cookbook、Anthropic cookbook、LangGraph 官方示例）：照着跑，改参数看变化。

- **产品拆解视频**：看别人怎么把 Agent 做成界面（你的强项，重点看交互）。
- **不看**：30 小时"从入门到精通"合集、纯概念讲解、念 PPT 的课。

## 3. 论文（只读这几篇，够用）

| 论文 | 为什么读 |
|---|---|
| ReAct | Agent 循环的源头，理解"思考-行动-观察"为什么有效 |
| Reflexion | 自我反思机制的收益与代价 |
| Lost in the Middle | 解释长上下文为什么失效 |
| RAG 原始论文（Lewis et al.） | 建立检索增强的基本框架 |
| Self-RAG / Corrective RAG | 拒答与自我纠错的思路 |
| Toolformer / Gorilla | 工具调用能力从哪来、参数幻觉为何发生 |
| GraphRAG | 何时图结构有意义，何时是过度设计 |

读法：只读 Abstract + Intro + 关键图 + 结论，30 分钟一篇，记"它解决什么问题、代价是什么"。

## 4. 工具栈（选一个深挖，其余知道边界）

**语言与模型（按你的实际库存定，不要再纠结）**

| 项 | 定下来的选择 | 理由 |
|---|---|---|
| 主语言 | **TypeScript / Node**（全部 5 个项目） | 你主要会 JS、Node 只是不熟；再引入 Python 等于同时学两件事，且 P0 网关与前端 UI 同语言能省一半时间 |
| Python | **只在读开源项目时用**，不写生产代码 | 面试被问"为什么不用 Python"有标准答法：Coding Agent 生态一半是 TS，前端转岗用 TS 能端到端交付 |
| 默认 provider | **DeepSeek**（已有 key） | 便宜、中文强、OpenAI 兼容协议，适合当主力；也是"成本工程"练习的真实素材 |
| 降级 / 对比 provider | 千问、MiniMax、OpenAI（都已有 key） | P0 网关要"3 家模型 + 失败降级"，正好用你手上的真实账号，不装假数据 |
| embedding / rerank | 先用千问或 OpenAI 的 embedding；rerank 用 bge-reranker API | 别自建模型，时间要花在评测和工程上 |

| 类别 | 候选 | 建议 |
|---|---|---|
| 编排 | LangGraph / OpenAI Agents SDK / Claude Agent SDK / Mastra / Dify | W8 对比后选 1 个深挖；Dify 只用来理解产品形态 |
| 前端 Agent UI | Vercel AI SDK / CopilotKit / assistant-ui | 你的强项区，选一个做深 |
| 向量库 | pgvector / Qdrant / LanceDB / Milvus | 个人项目用 pgvector 或 LanceDB，省运维 |
| 检索 | BM25（内置）/ bge-m3 / bge-reranker | 中文场景性价比最高 |
| 观测 | Langfuse（可自托管）/ LangSmith | 自托管优先，简历上能讲"我部署过" |
| 评测 | Ragas / promptfoo / 自建 | 自建 + Ragas 指标 |
| 沙箱 | E2B / Docker / Firecracker | 先 Docker，够用 |
| 部署 | Docker + 一台云主机 / Serverless | 别过度设计 |
| 协议 | MCP / A2A | MCP 必须会写 Server |
