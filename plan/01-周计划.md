# 24 周逐周计划（执行版）

> 起始：2026-11-09（W1）｜ 结束：2027-04-25（W24）｜ 默认每周 12h
> 用法：每周日晚复盘时勾掉本周"检查点"，答不出的记为红色，下周复考。
> 忙碌周（标 ⚠️）会降载：元旦、春节。不要试图补回来，直接顺延。

## 每周固定动作（无论多忙都要做）

- [ ] 至少 1 次有效 commit（代码或笔记）
- [ ] 周日晚 1h 复盘：写 `notes/周记-W{n}.md`（做了什么 / 卡在哪 / 下周改什么）
- [ ] 随机抽 3 道题库题自测（`plan/05-高频题库.md`）
- [ ] 更新能力雷达自评（W6 / W12 / W18 / W24）
