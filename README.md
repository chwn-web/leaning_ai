## 三张底牌（市场调研的结论，做任何取舍时回来看这两句）

1. **评测（Evals）是 2026 年唯一硬通货**——面试官 4/4 都会问"测试集哪来的、准确率怎么算"。所以评测集从 W9 就开始建，不等 W12。
2. **能讲清一条被追问三层还不塌的链路**，比多会三个框架值钱。三层 = 做了什么 → 为什么这么做（代价）→ 踩过什么坑、怎么发现的。

## 使用约定（给未来的自己，也给 AI 助手）

1. **每周日 1h 复盘**，写 `notes/周记-W{n}.md`，更新 commit 与卡点。这是计划的唯一校准机制。
2. **自评在 W6 / W12 / W18 / W24 复评**，达不到目标分就不进入下一阶段。
3. **视频/课程里有面试题或实战问题** → 抽出来写进 `plan/05-高频题库.md`，标注来源与考点，按主题回填到对应周。
4. **代码写在 `projects/` 下**，每个项目独立仓库，先写 README（含验收标准）再写代码。
5. 计划可以改，但**只能改范围，不能取消里程碑**。
6. **概念不懂/w 查资料后懂了 → 写成 `kb/02-概念/` 的一篇**（6 段固定结构），并在 `kb/00-索引.md` 加一行。不写下来就等于没学。
7. **每周日抽 2 篇知识库笔记合卷复述**，讲不顺的标红；每两周不看原文手画一次七层架构图。
8. 改了文档里的相对链接，跑一次 `node scripts/check-links.mjs` 确认没有死链。
